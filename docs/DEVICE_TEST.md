3. Tap "Listen": do you hear the pad? (A track with an audio file plays the file.)
4. Events: "RSVP / Reminder" downloads a calendar file? "Google Calendar" opens?
5. Booking: fill the 5 required fields, Submit. What message appears? (Email needs EmailJS to be set up.)
6. TikTok link opens TikTok or the browser?
7. Rotate the phone. Anything cut off or overlapping the player bar?
8. `/studio/`: Review inquiries, add a track, Export for publishing.
9. Pause animation button and your phone's "reduce motion" setting both stop the movement?
